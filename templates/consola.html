Consola SQL Interactiva

Escribe y ejecuta consultas SQL directamente contra la base de datos. Los resultados se limitan a 50 filas. Usa el selector de esquema para practicar con las tablas de los Problem Sets.

¿Qué es un esquema y por qué tengo que elegir uno? No te preocupes, es más simple de lo que suena

Un esquema es, básicamente, una carpeta dentro de la base de datos que agrupa tablas relacionadas. En este curso hay 4 carpetas:

Imaginalo como salones de un colegio.
Cada Problem Set tiene su propio salón con sus propias tablas adentro. El selector de Esquema de arriba le dice a la consola en qué salón buscar. Tú solo escribes el nombre de la tabla — SELECT * FROM schools — y la consola sabe en qué salón mirar.
  • public — las tablas del curso (libros, autores, puntuaciones…). Si estás haciendo los ejercicios de la Clase 0 o Clase 1, deja este.
  • dese — las tablas del Problem Set DESE (districts, schools, graduation_rates…). Si te tocó DESE, selecciona este.
  • moneyball — las tablas del Problem Set Moneyball (players, teams, salaries…). Si te tocó Moneyball, selecciona este.
  • packages — las tablas del Problem Set Packages, Please (addresses, packages, scans…). Si te tocó Packages, selecciona este.

¿Por qué existen los esquemas? Porque tres Problem Sets distintos pueden tener una tabla que se llame igual (por ejemplo, en otro curso podría haber un schools distinto). Los esquemas evitan que se pisen entre sí. Así cada práctica vive en su propio salón, ordenadito.

¿Qué tenés que hacer vos? Casi nada:

  • Elegí el esquema que te tocó en el selector de arriba (es un solo click).
  • Escribí tu SELECT normal, sin pensar en el esquema. Escribí FROM schools, no FROM dese.schools.
  • ¡Listo! La consola se encarga del resto.
✅ En resumen: un esquema es solo una carpeta. Elegí la tuya en el selector y concentrate en tu consulta. No tenés que hacer nada más.
